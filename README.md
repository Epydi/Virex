## 🛠 Tech Stack

*  **Language:** Written in high-performance **Rust**
*  **Package Source:** Direct **Git** repository support
*  **Interface:** Lightweight and intuitive **CLI**

## 🚀 Get Started

### Prerequisites
Make sure you have Rust and Cargo installed:
```bash
rustc --version
cargo --version
```
### Installation
Clone the repository and build the binary:
```bash
git clone [https://github.com/your-username/virex.git](https://github.com/your-username/virex.git)
cd virex
cargo build --release
```
You can check if everything setup correctly:
```bash
virex version
```
### Usage
```bash
virex install [package_name]
virex update
```
